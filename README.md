# Ashfall — Survive the Night of Cinders
An original gothic horde-survival web game. Pick a vigil (Warrior, Assassin, Mage, Archer), survive ten minutes in the crypt, then destroy the Ash Lord.
All art and sound are generated in code. Font: Cinzel (SIL Open Font License, see fonts/OFL.txt).
Play: https://ntony7898.github.io/ashfall/
